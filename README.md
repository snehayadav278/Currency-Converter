# 💱 Currency Converter

A simple and responsive web application that converts currencies in real-time.

## ✨ Features
- **Live Rates:** Fetches active currency conversions using Fawaz Ahmed's API.
- **Clean UI:** Responsive design with modern input styling.

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
- FontAwesome Icons

## 🚀 How to Run
Open `index.html` directly in any web browser or use VS Code's **Live Server** extension.
